# ПроАвто57 — новый дизайн

Адаптивный сайт автосервиса в Орле: анимированный первый экран, плавное появление секций при прокрутке, интерактивные категории прайса, мобильное меню.

## Запуск
Откройте index.html или выполните python -m http.server 8080 в папке проекта. Сборка и зависимости не нужны.

Контакты, услуги, ориентировочные цены и изображения взяты с https://proauto57.ru/ (17.11.2026). Исходный сайт не изменён. Эта версия не подключена к действующей системе записи: связь по телефону и почте. Данные посетителей не собираются.
